# 毛概自习室

本次52张照片中的298道选择题：197道单选、101道多选。

## 功能

- 全部题混合练习：随机打乱全部298题，每题一次；自动保存本轮顺序和进度。
- 章节练习：七个独立入口，点击即按照片题号练习整章；另支持自定义题型、题量及顺序。
- 七个章节：绪论26题、第一章44题、第二章50题、第三章30题、第五章50题、第六章53题、第七章45题。章节编号沿用照片。
- 模拟考试：自选时长，时间结束自动交卷，统一判分和回顾答案。
- 错题复习：错题自动收录，重新答对后移出。
- 练习记录：保存最近50次报告。

多选题需完全选对才得分。298题中有257题按用户最新提供的 Excel 题库核对，发现并校准91题的答案内容差异；11题与此前照片订正不同，在答案旁提示来源差异。Excel 未覆盖的41题保留原题和先前确认结果，包括第七章第25题答案A、第15题原选项A。Excel 另有一道“人民，只有人民，才是创造世界历史的动力”题未在照片题库中出现，本次未替换或增加题目。

题库的题干、选项和答案按内容配对，不能将其他选项顺序的答案字母直接套用。`tests/answer-reference.json` 保存257条参考答案内容，测试逐条比对，避免再次错位。答案要点展示正确选项原文。

更新时保留当前练习顺序、位置、标记和作答内容；按新选项顺序转换已选字母，重新计算报告。受影响题目的统计按最近50次报告及当前已确认作答重算，未受影响的统计保留。原始记录备份到浏览器存储键 `maogai-study-room-photos-20261101-v2-before-excel-audit`。记录保存在当前浏览器，不会跨设备同步。

## 本地运行

直接打开 `docs/index.html`，或使用任意静态服务器提供 `docs/` 目录。无需安装依赖或构建。

```sh
python -m http.server 8000 --directory docs
```

## 验证

```sh
node tests/core.test.cjs
node tests/session.test.cjs
```

## GitHub Pages

在仓库 Settings → Pages 中选择 Deploy from a branch，分支 `main`，目录 `/docs`。更新主分支后，GitHub 会自动发布最新网站。

网站使用相对资源路径，兼容 GitHub Pages 项目子路径。
